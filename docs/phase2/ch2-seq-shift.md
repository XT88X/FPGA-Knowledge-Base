# 2.2 时序逻辑与移位寄存器

## 从组合到时序：D 触发器

组合逻辑没有记忆，时序逻辑靠**触发器(Flip-Flop)**记住状态。最基本的是 **D 触发器**：

```verilog
always @(posedge clk or negedge rst_n) begin
    if (!rst_n) q <= 1'b0;
    else        q <= d;      // 只在 clk 上升沿把 d 锁存到 q
end
```

`@(posedge clk)` 表示只在时钟上升沿动作。这是 FPGA 一切时序的根基：**所有状态变化都对齐到时钟沿**，输出 `q` 在下一个沿才更新。

![D 触发器结构](../../../assets/phase2/dff-structure.svg)

要点：

- `<=` 是非阻塞赋值，时序逻辑专用，描述"沿到来时并行更新"。
- 异步复位写在敏感表 `or negedge rst_n`，块内先判复位。

## 移位寄存器

把多个 D 触发器首尾相接——前一级的输出接下一级的 D 端——就成了**移位寄存器**：

```verilog
always @(posedge clk or negedge rst_n) begin
    if (!rst_n) q <= 0;
    else        q <= {q[WIDTH-2:0], sin};   // 整体右移，sin 进最低位
end
```

每个时钟沿，所有位挪一格，`sin` 进入最低位。于是：

- **并行输出 `pout=q`**：经过 WIDTH 个时钟后，串行进来的位在 8 根线上同时出现 → **串入并出(SIPO)**。
- **最高位 `sout`**：可继续往下一级送，做**并入串出(PISO)**或级联扩展。

![移位寄存器时序](../../../assets/phase2/shift-reg-timing.svg)

代码 `shift_reg8.v` 即 8 位移位寄存器，`tb_shift_reg8.v` 串行送入 `1011_0100` 后并行读出比对。

## 流水灯：移位寄存器的直观应用

流水灯就是让一个"1"在 8 个 LED 里循环移动。用节拍计数器放慢移位速度：

- 50MHz、每步 250ms → 每拍时钟数 = `50,000,000 × 0.25 = 12,500,000`。
- 位宽 = `ceil(log2(12,500,000)) = 24 bit`（2^24=16.7M 够）。
- 循环左移：`led <= {led[6:0], led[7]};`

`water_led.v` 实现单向流水；`water_led_dir.v` 在此基础上用按键切换方向——它对按键做了**内置两级同步 + 下降沿检测**（完整的机械消抖见 2.3），检测到按下就翻转 `dir`，左移/右移：

- 左移：`{led[6:0], led[7]}`
- 右移：`{led[0],   led[7:1]}`

## 环形与扭环计数器

移位寄存器把输出反馈回输入，就成了**计数器**：

- **环形计数器(ring)**：把最高位接回输入，n 位移位寄存器循环出 n 个状态，独热编码。
- **扭环/约翰逊计数器(johnson)**：把**取反**的最高位接回输入，n 位出 2n 个状态，相邻状态只变一位，译码无毛刺。

![环形与扭环波形对比](../../../assets/phase2/ring-vs-johnson.svg)

它们是流水灯/顺序脉冲发生器的底层思想：不用写加法计数器，靠移位+反馈就能产生循环节拍。

## 关键计算小结

- 节拍计数 = `CLK_FREQ_HZ × STEP_MS / 1000`；本例 50MHz×250ms=12,500,000。
- 节拍计数器位宽 = `ceil(log2(节拍计数))`，本例 24 bit。
- 环形 n 位 → n 状态；扭环 n 位 → 2n 状态。
