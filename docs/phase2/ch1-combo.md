# 2.1 组合逻辑设计

## 什么是组合逻辑

**组合逻辑**的输出只由**当前输入**决定，没有记忆、没有时钟：输入一变，输出立刻跟着变（经过门级延迟）。与之相对的时序逻辑会记住历史状态，留到 2.2 讲。

最基本的组合单元是**与/或/非**门。由它们可搭出两类常用电路：

- **比较器**：判断两个数的大小（`==`、`>`、`<`）。Verilog 直接写关系运算符，综合器自动生成比较树。
- **加法器**：`assign s = a + b;` 综合成进位链（RCA/CLA）。做减法即补码加法。

在 FPGA 里，这些都由 LUT（查找表）实现——LUT 本质是一张真值表，输入一来直接查表出结果。

## 3-8 译码器

**译码器**把 `n` 位输入地址翻译成 `2^n` 路**独热(one-hot)**输出：同一时刻只有一路为 1。3-8 译码器即 3 输入译 8 路。

设计要点：

- `a[2:0]` 是地址，`en` 是使能。
- `en=1` 时按 `a` 选通对应输出；`en=0` 全部输出 0。
- 用 `always @(*)` + `case(a)` 描述，是纯组合逻辑，必须覆盖所有分支（写 `default`），否则会综合出锁存器（latch），这是组合逻辑的大忌。

![3-8 译码器结构](../../../assets/phase2/decoder38-structure.svg)

代码见 `code/phase2/decoder38.v`，`tb_decoder38.v` 会穷举 `a=0~7` 并比对独热输出。

## 七段数码管译码

一位七段数码管有 a~g 七段加一个小数点 dp。给它一个 4 位十六进制数 `0~F`，要译成哪几段点亮。

两个关键概念：

- **段码表**：共阴极性下，显示数字 `5` 需要点亮 `a/f/g/c/d` 段，对应段码 `7'h6D`。完整 0~F 表写在 `seg7_hex.v` 的 case 里。
- **共阴 vs 共阳**：共阴数码管公共端接地，段给**高电平**点亮；共阳公共端接 VCC，段给**低电平**点亮。用参数 `COMMON_ANODE` 切换，共阳时把共阴段码整体取反即可。

![七段段选定义](../../../assets/phase2/seg7-def.svg)

代码 `seg7_hex.v` 用 `COMMON_ANODE` 参数适配两种板子，`dp_i` 控制小数点。

## 多路选择器 MUX

**MUX** 从多路输入里选一路输出。`sel` 是选择信号：`sel=0` 选 d0，`sel=1` 选 d1……它和译码器是一体两面——译码器做"地址→独热使能"，MUX 做"选择→数据通路"。

`mux4.v` 用 `WIDTH` 参数化位宽：

- 位宽=1 时做通道/位选；
- 位宽=8 时，多位数码管动态扫描里可以把"当前点亮那一位要显示的段码"切出来。

**多位数码管动态扫描**就靠 MUX + 位选：人眼有视觉暂留，我们快速地一位一位轮流点亮（用译码器/MUX 选通某一位，同时把这一位的段码送上段选线），扫描频率高于 ~50Hz 时看起来几位同时都亮。这是 task-2-1-3 的核心思路。

## 竞争与冒险（毛刺）

**竞争(Race)**：同一个信号经过多条路径到达输出，延迟不同。**冒险(Hazard)**：由此在输出端产生短暂的**毛刺(glitch)**。

典型例子：`Y = A & ~A`，理论上恒为 0，但 `~A` 多走了一个反相器的延迟，在 A 跳变的极短窗口里两路暂时都为 1，Y 上就冒出一个窄脉冲。

![竞争冒险毛刺时序](../../../assets/phase2/hazard-glitch.svg)

毛刺对纯指示（如 LED、数码管段选）通常无所谓，但如果毛刺正好被触发器采样、或送入计数器使能端，就会误触发。消除思路：

1. **同步采样**：输出经过一级寄存器，只在时钟沿取稳定值——毛刺发生在两沿之间，采不进去。这是 FPGA 最常用的办法。
2. **加选通/采样使能**：等输出稳定后再用使能信号"开门"采样。
3. **卡诺图消险**：组合逻辑化简时增加冗余项，避免两个质蕴涵项相切（相邻卡诺圈边界处易出毛刺）。

## 关键计算小结

- 译码器输出路数 = `2^n`，3 输入即 8 路独热。
- 七段段选位宽 = 7（a~g），外加 1 位 dp，共 8 位。
- 动态扫描频率建议 ≥ 50Hz；8 位数码管每位点亮时间 = `1/(50*8) = 2.5ms`。
