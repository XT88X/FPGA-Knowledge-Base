# 4.4 综合项目 · 数字频率计

> 阶段 4 综合项目一：用"闸门法"测量方波频率，数码管显示 Hz/kHz/MHz 并自动换挡。
> 默认时钟 50MHz。本设计已通过结构校验与 testbench 自检；真实综合/时序/上板需在 Vivado 完成。

## 1. 测频原理：闸门法

频率 = 单位时间内脉冲个数。最直接的硬件做法：

1. 产生一个**精确闸门窗口**（默认 1 秒）；
2. 闸门高电平期间，对被测方波的**上升沿**逐个计数；
3. 闸门落下时，把计数值**锁存**——因为闸门是 1 秒，计数值就等于频率（Hz）。

![闸门法测频时序](assets/phase4/ch4-gate-timing.svg)

### ±1 个字误差
闸门起止时刻与被测信号沿是**异步**的：闸门打开时可能刚错过一个沿、也可能多抓一个沿。所以读数有 **±1 个字**的量化误差。

- 相对误差 ≈ `1 / N`（N 为计数值）。
- 闸门越长、被测频率越高，N 越大，相对误差越小；测低频（如 1Hz）时 1 秒闸门只数到 1，相对误差 100%。
- 工程上用**双 D 法 / 倒数法**（同时测周期）或**等精度测频**改善低频精度。

### 等精度测频（进阶了解，本项目不交付）
闸门由被测信号沿同步产生，使闸门严格等于被测信号整数个周期；同时在闸门内对一个高频标准时钟计数。这样无论被测频率高低，**量化误差恒定**（只差标准时钟的 ±1）。本仓库主交付用更直观的直接闸门法，等精度作为拓展方向。

## 2. 系统架构

![数字频率计系统框图](assets/phase4/ch4-freq-block.svg)

| 模块 | 职责 | 关键参数 |
|---|---|---|
| `ch4_gate_gen` | 由 50MHz 产生精确闸门 `gate`（高）与保持期（低），结束时出 `gate_done` 脉冲 | `GATE_TICKS`（默认 50,000,000=1s）、`HOLD_TICKS`（默认 5,000,000=0.1s） |

| `ch4_freq_meter_top` | 顶层互连 | — |

## 3. 关键参数计算

- **闸门计数器位宽**：要数 `GATE_TICKS=50,000,000` 个时钟 → `2^25=33.5M` 不够、`2^26=67M` 够，模块内用 32bit 计数器余量充足。
- **事件计数器位宽**：1 秒内最多数 50,000,000 个沿 → `2^26=67M` 够，取 `CNT_WIDTH=27` 留余量。
- **量程/单位切换**：

![量程与单位切换逻辑](assets/phase4/ch4-range-switch.svg)

```
count >= 1_000_000  ->  MHz，显示值 = count / 1_000_000
count >= 1_000      ->  kHz，显示值 = count / 1_000
否则                 ->  Hz，显示值 = count
```

  例：`count=12,345,000` → unit=MHz，显示整数 `12`（小数位在教学版暂不展开，可扩展小数点 BCD）。

- **BCD 转换**：量程缩放后的整数用 double-dabble（双 dabble）转 6 位 BCD，供数码管逐位显示。

## 4. 精度边界与上板注意事项

> 本仓库 `ch4_event_counter` 用**系统时钟采样被测信号边沿**，教学上易验证；但当被测信号接近 50MHz 时，采样法会丢边沿。
> 工业级做法：用被测信号本身做异步计数器（闸门使能），闸门结束后再把计数值**跨时钟域**同步到系统侧读取。上板如需测满 1Hz–50MHz，应把计数改为"被测时钟域计数 + 多级同步/握手读回"，并对 `sig_in` 做输入同步与约束。

- **跨时钟域**：`sig_in` 是异步信号，模块内已做 2 级同步；上板在 XDC 里对 `sig_in` 加异步输入约束。
- **数码管电平**：共阴/共阳由板卡决定，段码电平相反，按原理图确认（见 `code/common/fpga_common.xdc` 第 5 段）。
- **引脚**：本设计不写死引脚号，按 `code/common/fpga_common.xdc` 与 `docs/board-adaptation.md` 替换 `PACKAGE_PIN`。
- **资源**：单计数器 + 小状态机 + 数码管扫描，LUT/FF 占用极小，Artix-7 任意型号均可。

## 6. 验证说明

- `tb_ch4_gate_gen`：缩短闸门到 100 拍，核对 gate 高电平时长与 gate_done 脉冲次数。
- `tb_ch4_event_counter`：闸门内给 10 个已知上升沿，核对 count≈10（±同步对齐误差）、锁存、清零。
- `tb_ch4_freq_fsm`：直接喂 999 / 1000 / 1,000,000 / 12,345,000，核对单位切换与缩放值。
- `tb_ch4_seg7_scan`：核对 6 位位选轮询。
- `tb_ch4_freq_meter_top`：缩短闸门加速仿真，注入方波，核对读数在允许误差内、单位正确。
