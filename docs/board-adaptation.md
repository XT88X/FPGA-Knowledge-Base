# 板级适配指南（通用）

本知识系统**不绑定某一块开发板**。所有工程按"通用 Artix-7 / Zynq（Xilinx 7 系列）"写法组织，
引脚约束统一用占位模板 `code/common/fpga_common.xdc`。上板前，你只需要把自己板子的
时钟 / 复位 / LED / 串口等引脚号填进模板即可。

> 红线：**不要照抄本文件或模板里的任何引脚号**。不同批次、不同型号引脚完全不同。
> 一切以你手里那块板子的**官方原理图**和厂商提供的**参考 XDC（.xdc / .tcl 约束）**为准。

---

## 1. 通用适配方法论（5 步）

1. **确认芯片型号**：正点原子 / 野火的 Artix-7 开发板常见型号为 `XC7A10T`、`XC7A35T`、
   `XC7A50T`；Zynq 常见为 `XC7Z020`（CLG400 封装）。在 Vivado 新建工程时必须选对型号与封装。
2. **拿到厂商参考约束**：每块板的资料盘 / GitHub 仓库里都有对应每个实验的 `.xdc` 文件，
   里面已经写好了时钟、按键、LED、数码管、串口等的 `PACKAGE_PIN` 与 `IOSTANDARD`。
3. **照搬而不重推**：打开厂商参考 XDC，把 `clk / rst_n / led / txd / rxd` 等对应端口的
   `PACKAGE_PIN`、`IOSTANDARD` 原样复制进 `code/common/fpga_common.xdc`。
4. **核对电平标准**：多数 3.3V Bank 用 `LVCMOS33`；若某 Bank 是 1.8V，则该 Bank 引脚要用
   `LVCMOS18`。以原理图 Bank 电压为准。
5. **时钟周期按晶振填**：绝大多数正点原子 / 野火 Artix-7 板载主晶振为 **50 MHz**（周期 20 ns）；
   Zynq 板 PS 侧时钟由芯片自带，PL 侧常用 50 MHz 或 33.33 MHz 外部时钟，按参考 XDC 的
   `create_clock -period` 数值填写。

## 2. 在哪里找厂商的参考 XDC

| 板卡厂商 | Artix-7 代表型号 | Zynq 代表型号 | 参考约束位置（以官方最新资料为准） |
|---|---|---|---|
| 正点原子 | 开拓者 `XC7A10T`、达芬奇 `XC7A35T` | 领航者 `XC7Z020` | 资料盘 `2_程序源码/` 下对应实验工程里的 `*.xdc`；官方 GitHub 仓库 `ALIENTEK` 对应板卡目录 |
| 野火 | 征途系列 `XC7A10T / XC7A50T` |  Zynq 系列 `XC7Z020` | 野火官网下载中心对应开发板资料盘 `FPGA/实验工程` 内的 `constrs/*.xdc`；开源仓库 `EmbedFire` |

> 上表型号为常见公开型号，**具体封装（ffg484 / clg400 等）与引脚号务必以你购买板卡实物的
> 官方原理图和随板资料为准**；本表不提供具体引脚号，避免误导。

## 3. 时钟 / 按键 / LED 的常见规律（帮助你在原理图里快速定位）

- **时钟**：通常接在专用时钟引脚（MRCC/SRCC），原理图上标 `GCLK` / `SYS_CLK` / `50M`。
- **复位按键**：一般标 `RESET` / `KEY0`，外接上拉，按下为低电平（所以顶层用 `rst_n` 低有效）。
- **用户 LED**：标 `LED0~LEDn`，阳极接 VCC 经电阻（高电平点亮）或阴极接地（低电平点亮），
  看图确认是高有效还是低有效；必要时在 RTL 里取反。
- **按键消抖**：机械按键都会抖动，阶段 2.3 会专门讲；第一块 LED 实验可先不接按键。

## 4. 没有开发板怎么办？

完全可以先做纯软件学习：Vivado 自带 **Simulator** 行为仿真，本仓库每章都配了 testbench，
不接硬件也能看到计数器 / PWM 波形。等有板子再做引脚分配与下载。
