# 3.3 PWM 与模拟输出

PWM（Pulse Width Modulation，脉冲宽度调制）用数字方波的"占空比"来近似模拟电压，是 FPGA 驱动 LED 调光、蜂鸣器音调、电机速度的基础手段。

## 占空比与平均电压

PWM 输出是一串周期固定的方波。**占空比** = 高电平时间 / 周期。在 50% 占空比下，LED 一半时间亮一半时间灭；由于人眼视觉暂留，看起来亮度是"一半"。平均电压 ≈ 占空比 × 高电平电压。

```
pwm_out = (cnt < duty)
```

计数器 `cnt` 从 0 加到 2^N-1 溢出。`duty` 越大，高电平区间越长，占空比越高，LED 越亮。占空比分辨率为 1/2^N，8 位 PWM 即 1/256 级调光。

## 呼吸灯亮度包络

"呼吸灯"效果就是让 `duty` 在 0~255 之间缓慢地上升再下降，形成三角波包络。`SLOW_DIV` 控制变化速度：每数满 2^SLOW_DIV 个时钟才把 `duty` 加 1 或减 1。三路 PWM（RGB）的 `duty` 错开 85/170，形成三色呼吸不同步的彩虹效果。

## 蜂鸣器与音符频率

蜂鸣器靠方波驱动发声。音符频率 f 对应分频系数：

```
div = CLK / (2 * f)
```

50MHz 时钟下，C4=262Hz → div≈95419。每个音按简谱设定时长（多少个慢拍），播完自动切下一个音。《小星星》旋律：1 1 5 5 6 6 5 - | 4 4 3 3 2 2 1 - | ...

## 代码结构

- `pwm.v`：参数位宽 PWM 发生器，`pwm_out=(cnt<duty)`。
- `breathing_rgb_top.v`：三角波缓升缓降驱动三路 PWM，RGB 相位错开。
- `buzzer_music.v`：音符分频表 + 旋律 ROM，自动播放《小星星》。

> 蜂鸣器频率精度依赖分频系数取整；实际音高需上板用耳朵或示波器验证。
