# 3.1 UART 串口通信

UART（Universal Asynchronous Receiver/Transmitter，通用异步收发）是 FPGA 最常用的"和电脑对话"接口：两根线（TX/RX）、没有共享时钟、靠双方约定好的**波特率**逐位收发。本仓库用它实现"电脑发什么，FPGA 原样回什么"的串口回显。

## 帧格式：8N1

UART 没有时钟线，收发双方事先约定每秒传多少位（波特率）。一帧数据的标准结构为：

```
空闲(高) | 起始位(0) | D0 D1 ... D7 | 停止位(1) | 空闲(高)
```

- **空闲电平为高**。发送方一拉低就表示"一帧开始"（起始位）。
- **8 个数据位**，**LSB（最低位）先出**。
- **1 个停止位**为高电平，给接收机一点恢复时间。
- "8N1" 含义：8 数据位、N（无）校验、1 停止位。可选的偶/奇校验位本仓库先不启用。

例：发送字节 `0xA5 = 1010_0101`，线上依次出现的电平是 `1,0,1,0,0,1,0,1`（低位先）。

## 波特率与分频计算

波特率即每秒传输的位数。常用 `115200`。板载系统时钟 `50MHz`，要"每隔多少个系统时钟发一位"？

```
BIT_DIV = CLK_FREQ_HZ / BAUD_RATE
        = 50,000,000 / 115,200
        = 434.027...  → 整数取 434
```

即每位占 `434` 个系统时钟。实际波特率 = `50,000,000 / 434 ≈ 115,207`，与标称 115200 误差约 0.006%，远低于 UART 允许的 ±2%，完全可靠。

接收端为了在**每位正中间**采样（避开跳变沿毛刺），用 **16 倍过采样**：

```
OV_DIV = CLK_FREQ_HZ / (BAUD_RATE × 16)
       = 50,000,000 / (115,200 × 16)
       = 27.1  → 取 27
```

每 `27` 个系统时钟产生一个采样点，16 个采样点正好覆盖一个位宽。检测到起始位下降沿后把相位计数器复位，让"第 8 个采样点"落在每位中央。

## 发送模块 uart_tx（移位发送 FSM）

发送端比较简单：一个四状态 FSM `IDLE → START → DATA → STOP`，配合一个"每 BIT_DIV 个时钟打一拍"的波特率 tick。

- `IDLE`：`tx_out=1`，`tx_ready=1`；若 `tx_valid=1`，锁存 `tx_data` 进入 `START`。
- `START`：拉低 `tx_out`，等一个 tick。
- `DATA`：每次 tick 把 `shift[0]` 推到线上，右移一位，数满 8 位进入 `STOP`。
- `STOP`：拉高一个 tick，回到 `IDLE` 并置 `tx_ready`。

## 接收模块 uart_rx（过采样 + 多数表决）

接收端要"自己找位的中央"，比发送端多三步：

1. **输入同步**：`rx_in` 经过两级寄存器再使用，防止外部异步信号造成触发器亚稳态。
2. **下降沿检测**：空闲为高，一旦同步后的 `rx_sync` 变低，认为是起始位，启动接收。
3. **中点采样 + 多数表决**：在每位中央附近连续采 3 个样本（`samp_sh[2:0]`），3 取 2 得到该位值，抗毛刺。停止位中点采到 0 则置 `frame_err`。

收完 8 位后置 `rx_valid=1`（一个时钟周期脉冲），同时把字节放到 `rx_data`。

## 串口回显 uart_echo_top

把 rx 和 tx 拼起来：收到字节后锁存到 `echo_data`，拉高 `echo_req` 请求 tx 发送；tx 空闲（`tx_ready`）时把它发出去。这样电脑串口助手发一个字符，FPGA 就原样回一个字符。
