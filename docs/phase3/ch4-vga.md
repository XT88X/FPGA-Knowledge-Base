# 3.4 VGA 显示接口

VGA 是最经典的模拟显示接口：HSYNC（行同步）、VSYNC（场同步）、RGB 三色模拟信号。FPGA 通过产生标准时序让显示器输出图案。

## 640×480@60 标准时序

像素时钟 25.175MHz。一行 800 个像素时钟：

| 区间 | 像素数 | 说明 |
|---|---|---|
| 可见区 | 640 | 真正显示像素 |
| 前肩 | 16 | 消隐过渡 |
| 同步脉冲 | 96 | hsync 拉低 |
| 后肩 | 48 | 消隐过渡 |
| 合计 | 800 | |

一帧 525 行：480 可见 + 10 前肩 + 2 同步 + 33 后肩。

## 像素时钟生成

本设计用 50MHz 系统时钟，通过计数使能得到 25MHz 像素时钟（每 2 个系统时钟推进一个像素坐标），不依赖 MMCM/PLL。实际 25.175MHz 与 25MHz 误差 0.7%，显示器可容忍。

## 坐标生成

`vga_sync` 输出 `pixel_x`(0~639) 和 `pixel_y`(0~479)。在 `video_on=1` 时，根据坐标判断该像素应显示什么颜色。

## 代码结构

- `vga_sync.v`：产生 hsync/vsync/video_on 和 pixel_x/pixel_y 坐标。
- `vga_colorbar_top.v`：8 条竖彩条（白黄青绿品红蓝黑）。
- `vga_moving_block_top.v`：40×40 白方块在 640×480 内移动碰边反弹。

> VGA 时序参数参考 VESA 标准与 Project F 教程（访问日期 2026-10-10）。实际显示需上板接 VGA 接口 DAC（电阻网络）验证。
