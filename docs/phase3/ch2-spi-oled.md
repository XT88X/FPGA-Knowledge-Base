# 3.2 SPI 协议与 OLED 驱动

SPI（Serial Peripheral Interface）是四线同步串行总线：SCLK（时钟）、MOSI（主出从入）、MISO（主入从出）、CS_n（片选，低有效）。它比 UART 快得多，常用来驱动 OLED、Flash、ADC 等。本节用它点亮一块 0.96 寸 128×64 的 SSD1306 OLED。

## SPI 四种时序模式（CPOL/CPHA）

SPI 没有统一的"哪个边沿采样"，由两个参数决定：

- **CPOL（时钟极性）**：SCLK 空闲电平。CPOL=0 时空闲为低，CPOL=1 时空闲为高。
- **CPHA（时钟相位）**：在第几个时钟沿采样。CPHA=0 在第一个沿采样，CPHA=1 在第二个沿采样。

组合出四种模式。常用的是 **Mode 0（CPOL=0, CPHA=0）**：SCLK 空闲为低，主机在空闲相位把数据放到 MOSI，在 SCLK **上升沿**采样从机数据。SSD1306 在 Mode 0/3 下都能工作，本仓库 `spi_master` 默认 Mode 0。

SPI 是**全双工**的：每个 SCLK 周期主机发一位（MOSI）同时收一位（MISO），MSB 先出。

## SCLK 分频

SCLK 频率由系统时钟分频：

```
HALF = CLK_FREQ_HZ / (2 × SCLK_HZ)
```

例：50MHz、SCLK=1MHz → `HALF = 25`，SCLK 每 25 个系统时钟翻转一次，周期 50 个时钟 = 1µs。OLED 对 SCLK 速度不敏感，工程上常取 1~10MHz。

## SSD1306 OLED 基本操作

SSD1306 是 128×64 单色 OLED 驱动，内部有 1KB 显存（GDDRAM）。4 线 SPI 下多一根 **D/C（数据/命令选择）** 线：

- `D/C=0`：后面的字节是**命令**（设坐标、充电泵、对比度等）。
- `D/C=1`：后面的字节是**显示数据**（写进显存，点亮对应像素）。

### 显存映射

显存按 **8 个页（Page 0~7）** 组织，每页 128 列。每个页内一字节对应 8 行像素（bit0=最上行）。一个 **8×16 字符** 占两个页（上 8 行、下 8 行）× 8 列。

定位一个位置要先发三条命令：

```
0x00 | 列低4位     ; 列起始地址低字节
0x10 | 列高4位     ; 列起始地址高字节
0xB0 | 页号        ; 页地址
```

之后连续写 8 字节数据，列地址自动加 1。

### 上电初始化序列

上电后必须先发一串命令 OLED 才会正常显示，关键有：`0xAE`(关显示) → `0x8D,0x14`(开内部充电泵) → `0xA1/0xC8`(段重映射/扫描方向) → `0x81,0xCF`(对比度) → `0xA4,0xA6`(正常显示) → `0xAF`(开显示)。本仓库 `oled_ssd1306.v` 把这串命令固化在状态机里，复位后自动发送。

## 代码结构

- `spi_master.v`：参数化 SCLK 分频、CPOL/CPHA、片选，MSB 先出，全双工移位。
- `oled_ssd1306.v`：包一层 spi_master，自动跑初始化序列；对外提供 `char_col/char_page/char_code/char_wr` 写字符接口，内置数字 0/1 的 8×16 字模 ROM（可扩展为完整 ASCII）。
- `oled_top.v`：顶层，初始化完成后自动写两个字符。
